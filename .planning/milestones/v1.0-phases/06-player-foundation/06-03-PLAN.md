# Plan 06-03: Jellyfin Session Reporting, Lifecycle Resilience & Player Screen

## Objective

Implement the Jellyfin playback session reporting repository (`PlaybackRepository`) and lifecycle hook (`usePlaybackSession`) to accurately send `Start`, periodic throttled `Progress`, and `Stopped` events with playback ticks to the server. Build the dedicated player route `src/app/player/[id].tsx` and `PlayerScreen` component, ensuring playback state and position persist cleanly across device orientation changes and app state transitions (background/foreground) without restarting playback. Update Details screen to launch the player.

         - Throttles progress reporting: sends update every 8 seconds while playing, or immediately when paused/resumed.
         - Sends `reportPlaybackStopped` when player unmounts, ends, or leaves screen.
         - Listens to React Native `AppState`:
           - When transitioning from active to background: immediately reports current position and pauses progress loop.
           - When returning to active: resumes reporting loop.

       - Includes back navigation button (calls stop event before navigation).
       - State resilience: maintains playback instance and does not reload stream on orientation change or window resize.
