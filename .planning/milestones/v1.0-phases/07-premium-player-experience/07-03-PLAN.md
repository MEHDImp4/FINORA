# Plan 07-03: Skip Intro / Credits, Stats for Nerds & Player Screen Integration

## Objective

Implement dynamic Skip Intro / Skip Credits buttons based on chapter markers and playback position. Build the "Stats for Nerds" technical diagnostic modal overlay with sanitized URLs and stream metrics. Integrate gestures, overlay, bottom sheets, trickplay preview, skip markers, and technical stats into the primary `PlayerScreen` component.

       - Extend `MediaItem` with optional `chapters?: ChapterMarker[]`.

       - Extract `Chapters` from Jellyfin DTO:
         - Map `Name`, `StartPositionTicks`, `MarkerType` into `ChapterMarker[]`.

       - Props:
         - `chapters?: ChapterMarker[]`
         - `currentTimeSeconds: number`
         - `onSeek: (seconds: number) => void`
       - Behavior:
         - Determines if current time falls within intro range (e.g. between `IntroStart` and `IntroEnd`).
         - If within intro: renders "Skip Intro ⇥" button at bottom right (above controls).
         - Determines if current time is past `CreditsStart`:
           - Renders "Skip Credits ⇥" or "Next Episode" button.
         - On press: seeks directly to target position.
    4. Create `src/features/player/__tests__/SkipMarkerButton.test.tsx`:
       - Test button appears when current time is inside intro interval.
       - Test button is hidden when current time is outside intro interval.
       - Test press triggers seek to `introEnd` timestamp.
