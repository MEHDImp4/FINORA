# Plan 09-02: Haptics, Accessibility & Reduced Motion

## Objective

Deliver purposeful tactile feedback and screen reader accessibility (`UX-02`):
1. Create `HapticService` with light/medium impact, selection feedback, and error/notification feedback with safe fallback and disable toggles.
2. Enrich accessibility attributes across key components (`MediaCard`, `TimelineScrubber`, detail actions).
3. Ensure animations adhere to reduced-motion preferences.
