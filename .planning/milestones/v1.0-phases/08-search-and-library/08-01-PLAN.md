# Plan 08-01: Global Debounced Search, Category Filtering & Search History

## Objective

Implement universal, responsive Jellyfin media search (`SRCH-01`) featuring:
1. Debounced text query (<300ms) with request cancellation (`AbortController` via TanStack Query).
2. Category filtering chips: **All**, **Movies**, **Series**, **Episodes**, **People**.
3. Local search history persisted in `AsyncStorage` (max 10 entries, deduplicated, clearable, instant re-query on tap).
4. Interactive `SearchScreen` with virtualized results grid navigating directly to media details (`/details/[id]`).
