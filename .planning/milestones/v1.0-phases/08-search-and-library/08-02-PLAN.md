# Plan 08-02: Library Browse, Virtualized 3-Column Grid, Genre Filtering & Sorting

## Objective

Deliver the comprehensive library browser experience (`SRCH-02`):
1. Genre query support via `MediaRepository.getGenres()`.
2. Sorting options bottom sheet: Title (A-Z, Z-A), Release Date (Newest, Oldest), Rating (Highest, Lowest), Date Added (Newest, Oldest).
3. Virtualized 3-column media grid with `MediaCard` poster items, optimized for 60/120 FPS high refresh scrolling.
4. Library tabs / collection switching (Movies, TV Shows, Box Sets / Collections).
