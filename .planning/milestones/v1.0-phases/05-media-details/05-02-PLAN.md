# Plan 05-02: Series Details Screen, Season Switcher, Episode Cards & Card Navigation

## Objective

Implement TV series capabilities: fetching seasons and episodes from Jellyfin, building interactive `SeasonPicker`, `EpisodeCard` (with 16:9 thumbnails, episode metadata, and individual progress bars), and `SeriesDetailsView` with "Play Next Episode" quick action. Wire up card-to-details navigation from Home cards to the details route with instant touch feedback (<50ms).

       - Props: `{ episode: MediaItem; serverUrl: string; onPlay: (episode: MediaItem) => void }`.

         - In-progress red bar (`#E50914`) along bottom if `episode.playedPercentage > 0 && !episode.isPlayed`.

         - Runtime in minutes.

         - Pressable with <50ms touch feedback scale.
