# Plan 03-01: Domain Models, Mapper & Core Media Repositories

## Objective

Define clean FINORA domain entities (`MediaItem`, `MediaLibrary`, `UserProfile`), build resilient DTO mapping utilities that sanitize Jellyfin payloads and compute playback percentages, and implement `MediaRepository` and `UserRepository` to isolate UI components from raw backend structures.

---

## Tasks

<task id="03-01-01">
  <read_first>
    - package.json
    - .planning/phases/03-jellyfin-data-and-repositories/03-CONTEXT.md
    - .planning/phases/03-jellyfin-data-and-repositories/03-RESEARCH.md
  </read_first>
  <action>
    1. Create `src/types/media.ts` declaring strict domain interfaces:
       - `MediaType` ('Movie' | 'Series' | 'Season' | 'Episode' | 'BoxSet' | 'Unknown')
       - `MediaItem` (id, name, type, overview, year, runtimeMinutes, communityRating, genres, backdropImageTag, primaryImageTag, logoImageTag, blurhash, playbackPositionTicks, totalTicks, playedPercentage, isPlayed, isFavorite, seriesId, seriesName, seasonId, seasonIndex, episodeIndex)
       - `MediaLibrary` (id, name, collectionType, primaryImageTag)
       - `UserProfile` (id, name, serverId)
    2. Create `src/core/repositories/mediaMapper.ts`:
       - `mapJellyfinItemToMediaItem(dto: any): MediaItem`:
         - Normalizes ticks to minutes (10,000 ticks = 1 millisecond).
         - Computes `playedPercentage = (playbackPositionTicks / totalTicks) * 100` (bounded 0 to 100).
         - Extracts blurhash from `ImageBlurHashes.Primary` or `ImageBlurHashes.Backdrop`.
         - Safely handles missing/null attributes with sensible defaults.
       - `mapJellyfinViewToLibrary(dto: any): MediaLibrary`
    3. Create unit tests `src/core/repositories/__tests__/mediaMapper.test.ts` validating:
       - Accurate runtime and playback percentage calculations.
       - Graceful handling of missing or corrupted fields.
       - Blurhash extraction.
  </action>
  <acceptance_criteria>
    - `src/types/media.ts` exports all domain entities
    - `src/core/repositories/mediaMapper.ts` exports mapper functions
    - Unit tests in `mediaMapper.test.ts` pass
  </acceptance_criteria>
  <verify>
    <automated>npx jest --testPathPattern=mediaMapper.test.ts</automated>
  </verify>
</task>
