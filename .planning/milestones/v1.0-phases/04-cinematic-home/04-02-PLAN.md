# Plan 04-02: High-Performance Virtualized Carousels & Isolated Home Screen

## Objective

Build high-performance, virtualized horizontal carousels (`MediaCard` with 2:3 poster and 16:9 thumbnail variants with progress bars, and `MediaCarousel`), assemble the complete cinematic Home screen in `src/app/(tabs)/index.tsx`, and ensure isolated render trees so that Hero state updates do not trigger carousel re-renders.

         - `onPress?: (item: MediaItem) => void`
       - Visual specs:
         - `poster`: fixed width ~130dp, height ~195dp (2:3 aspect ratio).

         - If `item.playedPercentage > 0 && !item.isPlayed`: render red progress bar (`#E50914`) along bottom edge.
         - Text label: Primary title, year, and rating badge.
         - Pressable with subtle scale feedback on press (<50ms touch response).
         - Wrap in `React.memo` with custom comparator to prevent re-renders when parent lists scroll.
    2. Create unit tests `src/features/home/__tests__/MediaCard.test.tsx` verifying:

       - Renders thumbnail dimensions when specified.
       - Displays progress bar when `playedPercentage > 0`.
       - Dispatches `onPress` callback.
