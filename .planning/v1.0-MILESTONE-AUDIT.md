## 5. Security & Invariant Audit

- **Token Redaction**: `src/core/network/logger.ts` replaces `Authorization`, `X-Emby-Token`, `password`, `secret`, and `Cookie` values with `[REDACTED]`.
- **Storage Boundaries**: Hardware-backed keystore (`expo-secure-store`) stores auth tokens; `AsyncStorage` is restricted strictly to non-sensitive user preferences and local cache.
- **TLS Validation**: Cleartext HTTP connections display explicit security warnings; certificate validation cannot be bypassed.
- **Sandbox Media Storage**: Downloaded video files are isolated in private app directories, inaccessible to unauthorized external applications.
- **Accessibility & Motion**: Screen reader labels, roles, and adjustable values are present across buttons, cards, and scrubbers; shimmer animations disable loops when `AccessibilityInfo.isReduceMotionEnabled()` is active.
