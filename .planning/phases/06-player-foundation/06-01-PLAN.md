# Plan 06-01: FinoraPlayerEngine Abstraction & expo-video Integration

## Objective

Integrate `expo-video` into FINORA and implement the core `FinoraPlayerEngine` abstraction layer. The abstraction encapsulates the native video player into a clean domain state machine (`idle`, `loading`, `playing`, `paused`, `buffering`, `error`, `ended`), standardizing playback controls (`play`, `pause`, `seekTo`, `setVolume`, `setRate`) and exposing an ergonomic hook (`useFinoraPlayer`) so UI components never touch raw native player APIs directly.
