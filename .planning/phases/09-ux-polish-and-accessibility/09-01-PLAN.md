# Plan 09-01: Unified Screen States (Skeletons, Empty State, Error View & Offline Banner)

## Objective

Implement standardized, reusable screen state components (`UX-01`):
1. Pulsing shimmer skeleton primitives (`ShimmerSkeleton`, `MediaCardSkeleton`) respecting reduced motion.
2. Cinematic empty state component (`EmptyStateView`) with customizable iconography, messaging, and action button.
3. Robust error state component (`ErrorStateView`) with error explanation and user retry action.
4. Floating offline warning banner (`OfflineBanner`) for network disconnection awareness.
