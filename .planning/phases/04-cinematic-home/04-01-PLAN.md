# Plan 04-01: Dynamic Cinematic Hero Banner

## Objective

Install `expo-linear-gradient`, create `__mocks__/expo-linear-gradient.js`, and build the dynamic featured `HeroBanner` component with backdrop imagery, gradient blending into the dark surface, logo image with typography fallback, metadata badges, quick play button, and watchlist/favorite toggle.

---

## Tasks

<task id="04-01-01">
  <read_first>
    - package.json
    - src/types/media.ts
    - src/core/repositories/imageUrlBuilder.ts
    - .planning/phases/04-cinematic-home/04-CONTEXT.md
    - .planning/phases/04-cinematic-home/04-RESEARCH.md
  </read_first>
  <action>
    1. Install `expo-linear-gradient` (compatible with Expo SDK 52).
    2. Create `__mocks__/expo-linear-gradient.js` to mock `LinearGradient` in tests.
    3. Create `src/features/home/components/HeroBanner.tsx`:
       - Props:
         - `item: MediaItem | null`
         - `serverUrl: string`
         - `onPlay: (item: MediaItem) => void`
         - `onToggleFavorite?: (item: MediaItem) => void`
         - `onPressDetails?: (item: MediaItem) => void`
       - Visual Structure:
         - Full-width backdrop image via `expo-image` using `getBackdropUrl(serverUrl, item.id, item.backdropImageTag)` and `item.blurhash`.
         - LinearGradient overlay from transparent to dark background `#0A0A0C`.
         - Logo image if `item.logoImageTag` is present (using `getLogoUrl`), or bold title fallback using `FinoraText`.
         - Metadata badges: Release year, runtime in hours/minutes, community rating badge (`★ 8.5`), and primary genre chip.
         - Action buttons: Primary "Play" `FinoraButton` (<50ms touch response) and Watchlist / Favorite toggle button.
    4. Create unit tests `src/features/home/__tests__/HeroBanner.test.tsx` verifying:
       - Renders title when logo is missing.
       - Renders logo when `logoImageTag` is provided.
       - Displays metadata badges (year, rating, runtime).
       - Fires `onPlay` and `onToggleFavorite` callbacks on tap.
  </action>
  <acceptance_criteria>
    - `HeroBanner.tsx` renders backdrop, logo/fallback, badges, and action buttons
    - Tests in `HeroBanner.test.tsx` pass
  </acceptance_criteria>
  <verify>
    <automated>npx jest --testPathPattern=HeroBanner.test.tsx</automated>
  </verify>
