# Plan 03-02: Image Optimization, TanStack Query Setup & Data Hooks

## Objective

Implement display-matched, responsive image URL generation with blurhash support and downscaling options (`imageUrlBuilder`), configure the global TanStack Query provider with resilient caching policies, and implement custom query hooks for libraries, items, and details.
