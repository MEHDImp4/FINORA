# Plan 03-03: User Watch Progress, Resume Points & Favorite Mutations

## Objective

Implement `UserDataRepository` to synchronize watch progress, playback resume timestamps, played states, and favorite status with the Jellyfin server, along with optimistic mutation hooks for instantaneous user interaction feedback.

    1. Create `src/hooks/useUserDataMutations.ts`:
       - `useToggleFavorite(userId: string)`:
         - Executes optimistic update on `mediaKeys.detail(userId, itemId)` and cached item lists, flipping `isFavorite`.
         - Reverts to previous state on error.
         - Invalidates affected query keys on settlement.
       - `useMarkPlayed(userId: string)`:
         - Mutates played state optimistically, invalidating `mediaKeys.resume(userId)` and `mediaKeys.detail(userId, itemId)`.
