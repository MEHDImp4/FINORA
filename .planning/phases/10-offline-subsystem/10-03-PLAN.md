# Plan 10-03: Offline Playback & Reconnection Progress Sync

## Objective

Deliver offline playback integration and automatic reconnection progress dispatch (`OFFL-03`):
1. Create `OfflineSyncManager` that flushes queued watch progress events to Jellyfin when connectivity is restored.
2. Build `DownloadsScreen` to manage, inspect storage usage, and launch offline media playback.
3. Integrate offline media resolution with `PlaybackPlanner` / `FinoraPlayerEngine`.

    1. Create `src/features/offline/offlineSyncManager.ts`:
       - `syncPendingProgress(userId: string, playbackRepo?: PlaybackRepository, userDataRepo?: UserDataRepository): Promise<{ syncedCount: number }>`:
         - Retrieves pending entries via `offlineStorage.getPendingSyncEntries()`.
         - If empty, returns `{ syncedCount: 0 }`.
         - For each entry, reports to Jellyfin (calls `playbackRepo.reportPlaybackProgress` and `userDataRepo.markPlayed` if `isPlayed`).
         - Clears successfully synced entries from queue via `offlineStorage.clearSyncEntries()`.
    2. Create `src/features/offline/components/DownloadsScreen.tsx`:
       - Lists all downloaded media items (`FlatList`) with title, year, size in MB/GB, and download progress bar for active items.
       - Displays total storage consumed by offline items.
       - Provides "Play Offline" action button which launches player using the local file URI.
       - Provides "Delete Download" button with confirmation.
    3. Create `src/features/offline/__tests__/DownloadsScreen.test.tsx`:
       - Tests `DownloadsScreen` rendering offline items and active downloads.
       - Tests triggering play navigation with local path.
       - Tests deleting a downloaded item.
