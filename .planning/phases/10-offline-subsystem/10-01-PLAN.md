# Plan 10-01: Download Manager & File System Storage

## Objective

Build the native offline download subsystem (`OFFL-01`):
1. Manage downloads in the app private sandbox directory with state transitions (`idle`, `downloading`, `paused`, `completed`, `failed`).
2. Track download progress percentages and written bytes.
3. Provide pause, resume, and cancellation with automatic partial file cleanup.
