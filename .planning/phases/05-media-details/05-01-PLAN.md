# Plan 05-01: Movie Details Screen with Backdrop, Cast, Specs & Actions

## Objective

Extend FINORA domain models and mappers to extract cast/crew, media specs, and official ratings. Build the cinematic `MovieDetailsView` component featuring dynamic backdrop, gradient blending, logo/typography fallback, metadata badges (rating, runtime, specs), synopsis, horizontal cast carousel, and quick Play/Resume/Watchlist actions. Create dynamic route `src/app/details/[id].tsx` with instant (<50ms) touch feedback and back navigation.
