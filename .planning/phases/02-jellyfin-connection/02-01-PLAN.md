# Plan 02-01: Server Discovery, URL & TLS Validation, and Client Identification

## Objective

Install `@jellyfin/sdk` and `expo-crypto`, implement URL normalization and TLS/HTTPS validation with unencrypted HTTP warning, build persistent client identification with unique device installation ID, and create the core Jellyfin client singleton.

---

    - .planning/phases/02-jellyfin-connection/02-RESEARCH.md
  </read_first>
  <action>
    1. Install `@jellyfin/sdk` and `expo-crypto` (compatible with Expo SDK 52).
    2. Create `src/core/jellyfin/clientInfo.ts`:

<task id="02-01-02">
  <read_first>
    - src/core/network/httpClient.ts
    - src/core/jellyfin/clientInfo.ts
    - .planning/phases/02-jellyfin-connection/02-CONTEXT.md
  </read_first>
  <action>
    1. Create `src/core/jellyfin/serverDiscovery.ts`:
       - `normalizeServerUrl(input: string): { url: string; isHttps: boolean; hasWarning: boolean; warningMessage?: string }`:
         - Trims whitespace, removes trailing slashes.
         - Adds `https://` if protocol omitted, or preserves `http://`.
         - Validates host syntax using `URL`.
         - If `http://`, sets `isHttps: false`, `hasWarning: true`, and `warningMessage: "Warning: Connecting over unencrypted HTTP. Your credentials and streaming data will not be encrypted on the local network."`.
       - `validateAndDiscoverServer(inputUrl: string, httpClient?: HttpClient): Promise<ServerDiscoveryResult>`:
         - Normalizes URL.
         - Calls `/System/Info/Public`.
         - Validates that response contains `Id` and `ServerName`.
         - Returns server metadata (`serverId`, `serverName`, `version`, `url`, `isHttps`, `warningMessage`).
    2. Create `src/core/jellyfin/jellyfinClient.ts`:
       - Create factory and singleton for Jellyfin API client wrapping `@jellyfin/sdk` (or configured `HttpClient`), dynamically setting base URL and authorization headers.
    3. Create unit tests `src/core/jellyfin/__tests__/serverDiscovery.test.ts` testing valid HTTPS, local HTTP warnings, invalid URLs, and `/System/Info/Public` parsing.
  </action>
  <acceptance_criteria>
    - `src/core/jellyfin/serverDiscovery.ts` correctly flags unencrypted HTTP URLs with `hasWarning: true`
    - `src/core/jellyfin/jellyfinClient.ts` initializes client with FINORA identification
    - Unit tests in `serverDiscovery.test.ts` pass
  </acceptance_criteria>
  <verify>
    <automated>npx jest --testPathPattern=serverDiscovery.test.ts</automated>
  </verify>
</task>
