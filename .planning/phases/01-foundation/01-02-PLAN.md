# Plan 01-02: Centralized Networking, Error Hierarchy & Credential-Scrubbed Logger

## Objective

Implement the runtime network polyfills, custom typed error hierarchy, resilient HTTP client with timeouts and exponential backoff retry, and a centralized logger that automatically redacts sensitive authorization tokens, passwords, and cookies from all logs.

### Truths
- All logger outputs scrub Authorization and X-Emby-Token headers
- Network errors are mapped to strongly typed FinoraError hierarchy

### Prohibitions
- No console logs containing raw Authorization headers or plaintext passwords
- No unhandled network promise rejections
