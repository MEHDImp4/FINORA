# FINORA Screenshots Guidelines

This directory stores official application screenshots referenced in `README.md` and `README.fr.md`.

## Recommended Filenames

| Filename | Screen | Description |
|---|---|---|
| `01-home.png` | Home Feed | Hero backdrop banner, Continue Watching carousel, and media rows |
| `02-details.png` | Media Details | Movie/Series backdrop, synopsis, season picker, and episode cards |
| `03-player.png` | Video Player | Fullscreen player with gesture indicators, controls, or subtitle styling |
| `04-search.png` | Library & Search | Live search results, filters, or library grid |
| `05-downloads.png` | Offline Downloads | Background download queue and completed media items |

## Format Specifications
- **Aspect Ratio**: 9:16 or 9:19.5 (standard modern smartphone portrait resolution)
- **Resolution**: 1080×2340 or 1080×2400 (PNG or WebP)
- **Content**: Use royalty-free open media (e.g. Blender Foundation films: *Big Buck Bunny*, *Elephants Dream*, *Sintel*, *Tears of Steel*) or demo server content. Never include copyrighted movies or personal server domains.
