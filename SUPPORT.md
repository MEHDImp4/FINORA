# Getting Support with FINORA

Welcome! We are excited to have you in the FINORA community. This guide will help you find the right channel for your needs.

---

## 💬 General Questions, Setup & Ideas
For questions about server configurations, hardware compatibility, feature suggestions, or general discussion:
👉 **[GitHub Discussions](https://github.com/MEHDImp4/FINORA/discussions)**

Available discussion categories:
- **Announcements**: News, updates, and releases from maintainers.
- **General**: Open community chat about personal streaming and FINORA.
- **Ideas**: Brainstorm new features, UI improvements, and UX flows.
- **Q&A**: Ask technical questions and get help from the community.
- **Show and tell**: Share your server setup, client hardware, or custom deployments.

---

## 🐛 Bug Reports & Playback Issues
If you encounter unexpected behavior, crashes, or video playback difficulties:
1. Search existing [Issues](https://github.com/MEHDImp4/FINORA/issues) to see if the issue is already tracked.
2. If new, open an issue using the appropriate form:
   - 🐛 **[Bug Report Form](https://github.com/MEHDImp4/FINORA/issues/new?template=bug_report.yml)**
   - 🎬 **[Playback Issue Form](https://github.com/MEHDImp4/FINORA/issues/new?template=playback_issue.yml)**

> ⚠️ **Security Notice**: Never paste authentication tokens, passwords, or personal server addresses into public issues or logs.

---

## 🛡️ Security Vulnerabilities
If you discover a security vulnerability, credential leakage, or authentication bypass:
👉 Please consult our **[Security Policy (SECURITY.md)](SECURITY.md)** to submit a confidential report. **Do not create public issues for security vulnerabilities.**

---
